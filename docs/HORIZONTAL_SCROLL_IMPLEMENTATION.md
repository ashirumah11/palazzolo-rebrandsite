# PTVTI Horizontal Scrolling Component

## Overview

A reusable global horizontal scrolling system for the PTVTI website, designed to handle content that extends beyond available horizontal space on various screen sizes. The component provides smooth, accessible scrolling for cards, lists, and other content elements.

## Files

- **CSS:** `static/css/horizontal-scroll.css` (5.9KB)
- **JavaScript:** `static/js/horizontal-scroll.js`

## CSS Classes

### Core Container Classes

| Class | Description |
|-------|-------------|
| `.horizontal-scroll-section` | Section wrapper with proper positioning and width |
| `.horizontal-scroll-container` | Main scrollable container (flexbox with overflow-x) |
| `.horizontal-scroll-content` | Content wrapper inside the container |
| `.horizontal-scroll-item` | Individual scrollable item (flex: 0 0 auto) |

### Scrollbar Classes

| Class | Description |
|-------|-------------|
| `.horizontal-scrollbar-track` | Track background for custom scrollbar |
| `.horizontal-scrollbar-thumb` | Visible thumb element gradient from gold to gold-dark |

### Control Classes

| Class | Description |
|-------|-------------|
| `.horizontal-scroll-controls` | Container for left/right navigation buttons |
| `.horizontal-scroll-button` | Circular nav buttons with hover/focus states |

### Section-Specific Classes

| Class | Use Case |
|-------|----------|
| `.department-scroll-container` | Department filter tabs/buttons |
| `.course-scroll-item` | Course cards |
| `.event-scroll-item` | Event cards |
| `.news-scroll-item` | News/article cards |
| `.testimonial-scroll-item` | Testimonial cards |
| `.accreditation-scroll-container` | Accreditation logos |

## HTML Structure

```html
<div class="horizontal-scroll-section">
  <h5 class="mb-3">Section Title</h5>
  <div class="horizontal-scroll-container department-scroll-container" role="region" aria-label="Descriptive label">
    <!-- Scrollbar track and controls (generated by JS) -->
    <div class="horizontal-scrollbar-track">
      <div class="horizontal-scrollbar-thumb"></div>
    </div>
    <div class="horizontal-scroll-controls">
      <button class="horizontal-scroll-button prev" aria-label="Scroll left">
        <i class="fas fa-chevron-left"></i>
      </button>
      <button class="horizontal-scroll-button next" aria-label="Scroll right">
        <i class="fas fa-chevron-right"></i>
      </button>
    </div>
    <div class="horizontal-scroll-content">
      <div class="horizontal-scroll-item">
        <!-- Your content (cards, buttons, etc.) -->
      </div>
    </div>
  </div>
</div>
```

## JavaScript API

### HorizontalScrollController Class

```javascript
class HorizontalScrollController {
  constructor(container, options = {})
}
```

#### Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `scrollAmount` | number | 300 | Pixels to scroll per button click |
| `thumbRatio` | number | 0.3 | Initial thumb width ratio |
| `autoHideDelay` | number | 3000 | Delay before hiding controls (ms) |

#### Methods

| Method | Description |
|--------|-------------|
| `init()` | Initialize the scroll controller |
| `destroy()` | Clean up event listeners and DOM |

### Auto-Initialization

The component auto-initializes when the DOM is ready:

```javascript
document.addEventListener('DOMContentLoaded', function() {
  document.querySelectorAll('.horizontal-scroll-container').forEach(container => {
    new HorizontalScrollController(container).init();
  });
});
```

### Homepage Accreditation Strip

```html
<div class="horizontal-scroll-section">
  <div class="container">
    <div class="horizontal-scroll-container accreditation-scroll-container" role="region" aria-label="Accreditation logos">

      </div>
```

## Accessibility Features

- **ARIA Labels:** All regions have descriptive `aria-label` attributes
- **Keyboard Navigation:** Arrow keys support via JavaScript controller
- **Focus States:** Visible focus indicators on scroll buttons
- **Screen Reader Support:** `role="region"` identifies scrollable sections

## Responsive Behavior

### Mobile (< 768px)
- Scroll items minimum width: 200px
- Scroll items maximum width: adjusted per component type

### Desktop (< 1200px)
- Standard spacing and gap values
- Cards sized appropriately for grid display

### Large Screens (≥ 1200px)
- Increased minimum widths for better visual density
- Extended maximum widths for larger cards

## Browser Support

- Chrome 69+ (Overflow scroll behavior)
- Firefox 66+ (scrollbar-width)
- Safari 12+ (-webkit-overflow-scrolling)
- Edge 79+
